## Run

Requirements: Flutter stable (developed with 3.47 / Dart 3.13), Xcode for iOS,
Android SDK for Android.

```bash
flutter pub get
flutter run            # on a connected device / emulator
flutter test           # unit + widget tests
flutter analyze
```

## Forehead mode

Landscape-locked. After «شروع» the player puts the phone on the forehead; once
it is held still and upright for ~1 s the neutral tilt is recorded
(calibration) and the 3-2-1 countdown starts. Tilt down (screen to the floor)
= correct, tilt up = pass. `TiltDetector` low-pass filters the accelerometer,
triggers at ±40° from the calibrated neutral, and needs the phone back in the
neutral zone (±20° for 250 ms, 700 ms cooldown) before the next action, so one
nod never counts twice. If no motion sensor answers within 1.5 s the game
falls back to on-screen Correct/Pass buttons. Tune thresholds in
`lib/features/game/domain/tilt_detector.dart` after testing on real phones.

Game rules live in `GameState` (immutable, no timers/I/O) so they are fully
unit-tested; `GameController` only adds the clock and word picking.

## Adding a word category

Edit `assets/words/words_fa.json` only — no code changes:

```json
{
  "id": "unique_id",
  "title": "عنوان دسته",
  "emoji": "🎲",
  "words": { "easy": ["…"], "medium": ["…"], "hard": ["…"] }
}
```

- `id` must be unique and stable (it keys the "already seen" history).
- Duplicates are dropped automatically after Persian normalization
  (Arabic ي/ك vs Persian ی/ک, ZWNJ, spacing).
- Content rules: no +18, politics, religion or controversial public figures.
- `flutter test` checks the pack parses and every level is non-empty.

Words go through the `WordRepository` interface, so downloadable packs can be
added later without touching game logic.

## Language

Persian is primary. The app picks Persian when any preferred device language is
Persian, English when the device's first language is English, otherwise
Persian; users can override in Settings. English uses the small
`words_en.json` pack.

## Ads, store builds and keys

Details: [docs/ads.md](docs/ads.md). In short:

```bash
dart run tool/store.dart bazaar          # dev | play | bazaar | myket | ios
flutter pub get                          # (or the command the tool prints)
cp ad_keys.example.json ad_keys.json     # fill in; git-ignored
flutter build apk --dart-define=STORE=bazaar --dart-define-from-file=ad_keys.json
```

The committed profile is `dev` (all ad SDKs, for tests/analysis). Never ship a
`dev` build. Store flavors, signing and release checklists come in M6
(`docs/store_notes.md`).
